Exact homogeneous repair theorem

Number the service slots 0,...,N-1 and cumulative boundaries 0,...,N. An arrival in slot r has exclusive deadline r+D and may execute only in r,...,r+D-1. Let Xhat_t be cumulative candidate service after t slots, c_s the available service in slot s, and C_t=sum_{s=0}^{t-1} c_s. Let L_t and U_t be the exact nondecreasing deadline and release prefix boundaries. Initial work is available at boundary zero but retains each original deadline; cumulative service itself starts at Xhat_0=0. A fixed terminal total is imposed by L_N=U_N. Exact raw increments satisfy 0<=Xhat_{t+1}-Xhat_t<=c_t.

Define the propagated corridor

    ell_t = max_{s>=t} { L_s - (C_s-C_t) },
    u_t   = min_{s<=t} { U_s + (C_t-C_s) }.

The corridor is feasible only if ell_t<=u_t at every boundary. Both envelopes are nondecreasing and their slot increments lie in [0,c_t]. They are obtained in O(N) exact arithmetic by

    ell_N=L_N; ell_t=max(L_t,ell_{t+1}-c_t),
    u_0=U_0; u_{t+1}=min(U_{t+1},u_t+c_t).

Set Xtilde_t=min(u_t,max(ell_t,Xhat_t)) and xtilde_t=Xtilde_{t+1}-Xtilde_t. Pointwise min/max preserves nondecreasing paths with the same capacity bounds, so xtilde satisfies every original service prefix, nonnegativity, service capacity and fixed endpoint exactly.

Proof of perturbation bound

Suppose the exact residual bounds are L_t-Xhat_t<=epsilon_d and Xhat_t-U_t<=epsilon_r. For s>=t, the raw capacity bound gives Xhat_s-Xhat_t<=C_s-C_t, whence L_s-(C_s-C_t)<=Xhat_t+epsilon_d. Taking the maximum proves ell_t-Xhat_t<=epsilon_d. For s<=t, the same capacity inequality gives U_s+(C_t-C_s)>=Xhat_t-epsilon_r; taking the minimum proves Xhat_t-u_t<=epsilon_r. Therefore

    -epsilon_r <= delta_t=Xtilde_t-Xhat_t <= epsilon_d.

Since delta_0=0, each change delta_{t+1}-delta_t has absolute value at most epsilon_r+epsilon_d. Thus

    sum_{t=0}^{N-1} |xtilde_t-xhat_t| <= N(epsilon_r+epsilon_d).

The module independently recomputes all repaired prefix and increment conditions using Fraction arithmetic. It rejects raw capacity/nonnegativity violations, infeasible propagated corridors, an inconsistent terminal state, and initial cohorts whose deadlines do not fit the homogeneous pre-origin contract. It never silently treats a floating-point tolerance as exact feasibility. More general electrical ramps, mixed deadlines and nonpreemptive jobs require the original coupled repair programme.

Monetary correction

For the actual public accounting function, cash(book)=Delta t sum[RT*G+PVcurtail], with a separate Delta t*|G-Greference| import-deviation charge; both supplementary rates equal one dollar/MWh. For repaired versus candidate service, a safe correction is

    B_R=sum Delta t[(|RT|+1)|Delta G|+|Delta PVcurtail|]+|Delta Psi|.

Because both positive-part physical maps are PUE*k-Lipschitz,

    B_R <= sum Delta t*k*PUE*(|RT|+2)|Delta x| + |Delta Psi|.

The corrected witness floor is Hsafe=Hraw-evaluation_allowance-B_R. This does not require the repair to be optimal, only exactly feasible. Negative RT prices are covered by the absolute price coefficient. Tail service is priced once under the declared terminal convention.
